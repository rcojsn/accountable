## How to run

Prerequisites (once): Node 24 or later, [uv](https://docs.astral.sh/uv/), Google Chrome (for the end-to-end tests). The first `npm run dev` or `uv sync` needs internet once, so uv can fetch Python 3.12; after that the app runs offline.

- `npm run dev`: installs anything missing, starts the backend (port 8000) and frontend (port 5173), opens the browser. Ctrl+C stops both. Change ports with `ACCOUNTABLE_API_PORT` and `ACCOUNTABLE_WEB_PORT`.
- `npm test`: Vitest, then pytest, then Playwright (which starts its own app on ports 8100 and 5180 with its own database in `e2e/.data/`). Stops at the first failing suite.
- `npm run seed`: resets the database (`backend/data/accountable.db`, or `ACCOUNTABLE_DB`) to fresh sample data.
